# Diagnóstico intermediário — fixture v2

As duas passagens Intel foram interrompidas no terceiro trecho (exit 1). A fixture gerava cada par de nós isoladamente, omitindo as curvas de ligação de `Layout.route` e provocando desvio na transição. Os dados são preservados como evidência intermediária e não entram na comparação final. A fixture v3 divide uma única rota arredondada em trechos com pontos compartilhados. O percurso completo foi verificado antes de repetir as medições.
